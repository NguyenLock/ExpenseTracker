# ExpenseTracker (Frontend)

Next.js App Router + TypeScript + Tailwind CSS.

## Scripts

```bash
npm run dev      # http://localhost:3000
npm run build
npm run start
npm run lint
npm run format
```

## Stack

- Next.js 16 / React 19
- TypeScript
- Tailwind CSS 4
- ESLint + Prettier
- `clsx` + `tailwind-merge` (`cn` in `src/lib/utils.ts`)
- `lucide-react` icons
